
## Test Rig Details
The physical testing was conducted on a scaled RC vehicle platform.
* **Chassis Architecture:** Telelever front suspension and a trailing swingarm rear suspension.
* **Isolation:** All data was gathered from the rear trailing swingarm, with the front suspension isolated from terrain inputs during testing to prevent cross-contamination of chassis dynamics.
* **Rear Suspension Specifications:**
  * Wheel Travel: 110mm
  * swingarm leverage ratio: ~5
  * Leverage Ratio: Progressively stiffer shock-to-wheel curve.
* **Damper Configurations:** Three physically identical basic orifice-style dampers were used (no shim stacks). Each damper shared the exact same spring rate and preload settings. The **only** variable modified across the tests was the damper oil viscosity.

* **NOTE:** The setup while using basic Orifice style dampers implemented a proprietary multi damper with internal linkage setup for a distributed damping and non linear ramp up across its stroke.
